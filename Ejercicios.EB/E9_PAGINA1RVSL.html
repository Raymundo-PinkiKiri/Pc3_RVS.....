¿Para qué sirve el diseño web de páginas web?

Para contar y ejecutar las herramientas para el diseño de páginas online, con el objetivo de crear adecuadamente
la identidad de una empresa. Así mismo, utilizar las versiones más recientes de software de diseño tales como Adobe,
y herramientas de programación para la construcción de sitios web.

El diseño web, se puede aplicar en cualquier tipo de empresa o producto, que se desee presentar a los usuarios
que utilizan el internet para buscarlos.

Un diseñador de sitios web, no crea únicamente páginas, va más allá, debe analizar las necesidades del cliente y los
objetivos para desarrollar un sitio web, a fin de brindar a los usuarios o visitantes la mejor experiencia y que luego
le motive a regresar.
